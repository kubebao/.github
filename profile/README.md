# KubeBao

**Kubernetes-native lifecycle management for OpenBao.**

KubeBao is an independent open-source project. Its main project is [OpenBao Operator](https://github.com/kubebao/openbao-operator), which installs and operates OpenBao clusters on Kubernetes.

OpenBao Operator is not an official OpenBao project.

- [Project website](https://kubebao.org/)
- [Operator documentation](https://docs.kubebao.org/)
- [Contributor guide](https://docs.kubebao.org/contribute/)
- [Project move and API-group migration](https://github.com/kubebao/openbao-operator/issues/785)

The repository transfer is complete. The Kubernetes API remains `openbao.org/v1alpha1`; an API-group migration requires a separate release.
