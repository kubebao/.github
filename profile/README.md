# KubeBao

**Kubernetes-native lifecycle management for OpenBao.**

KubeBao is an independent open-source project. Its main project is [OpenBao Operator](https://github.com/dc-tec/openbao-operator), which installs and operates OpenBao clusters on Kubernetes.

OpenBao Operator is not an official OpenBao project.

- [Project website](https://kubebao.org/)
- [Operator documentation](https://dc-tec.github.io/openbao-operator/)
- [Contributor guide](https://dc-tec.github.io/openbao-operator/contribute/)
- [Project move and API-group migration](https://github.com/dc-tec/openbao-operator/issues/785)

The operator repository is preparing to move to KubeBao. The links above point to its current home.
